Welcome to Sakerhet

Sakerhet is the Swedish word for security. It is a Discord bot written in Rust. It helps keep your server safe. It stops raids, deletes bad links, locks your server when needed, and lets people send anonymous messages.

Status: This bot is still being built. Some things on this page may not work yet.

When you add the bot

The bot makes a new category and a new text channel called Sakerhet. Only the owner and admins can see it. The bot posts a welcome message there. If anyone types in that channel, the message is deleted right away.

The bot asks for these permissions: Manage Channels, Manage Roles, Manage Messages, Kick Members, Read Message History, Send Messages and Embed Links.

Anonymous messages

Run /anonsend. Only you can see the bot's reply. Press the button to open a form. Type your message. You can also type a nickname. If you leave the nickname empty, it uses Anonymous.

The bot then posts it in the channel, like this: Anonymous said: Claude is a good AI Model.

The bot saves only the nickname and the message. It never saves your Discord user ID or your profile picture.

Bulk delete

Run /bulkdelete and pick one of two options: delete your messages in every channel, or only in this channel.

  • The first time, the bot asks you to make a password. This is not your Discord password. Please remember it. You type it twice to confirm.
  • The bot saves only a hash of the password (argon2id) next to your user ID.
  • After that, run the command again and type your password to start deleting.
  • Too many wrong tries will lock you out for a while.
  • Discord only lets bots delete in bulk for messages under 14 days old. Older messages are deleted one by one, so it can take a long time.

Lockdown

A lockdown turns off these things for the @everyone role:

  • Send messages and create posts
  • Send messages in threads and posts
  • Create public threads
  • Create private threads

When you run /unlock, the bot only turns back on what was on before. So if something was always off, it stays off.

The bot posts "Lock down was started." and "Lock down was ended." in the Sakerhet channel. If the channel is gone, the bot makes it again.

Raid protection

The bot keeps a suspicion meter for each server. It goes up and down over time. It goes up when:

  • Many people join fast, for example more than 5 in a minute.
  • One person sends lots of messages in a short time.
  • One message mentions the same person more than 4 times.

The bot deletes those messages and kicks the people who sent them. If a huge number of people join at once, the bot starts a lockdown by itself. It ends the lockdown after 10 minutes with no new joins from accounts made in the last 14 days.

Admins can change how strict this is with /config.

Bad links

The bot deletes messages that have links to NSFW websites or NSFW Discord servers, almost right away. It uses public block lists. The bot owner can add more with /nsfwadd. The bot logs the user ID, the link and the time. See the privacy page.

Privacy Policy

Last updated 21 November 2026.

This page explains what Sakerhet stores about you, why, and how to get it deleted. We try to keep it short and simple. We try to store as little as we can.

The short version: Sakerhet keeps your user ID and a hash of your bulkdelete password. It also keeps a short log when you post a blocked link. Anonymous messages are saved without your user ID. You can delete your data at any time with /forgetme.

Who we are

Sakerhet is a free and open source Discord bot. It is made by kynorie. The code is on GitHub. You can reach us in the Discord server or by opening an issue on GitHub.

What Sakerhet does not store

Sakerhet does not store your messages, your profile picture, your username or anything else about your Discord profile. The only exceptions are the items in the table above.

How the bot reads messages

To find bad links, message floods and mention spam, the bot has to see messages in the servers it is in. It checks each message as it arrives and does not save it. The only thing it saves is the blocked link log in the table above.

Who can see your data

  • Other users and server admins cannot see your data, and they cannot see your password.
  • Your password is only stored as a hash, so nobody can read it.
  • The data is stored in files on the server that runs the bot. Only the bot owner can open those files.
  • We do not sell your data. We do not share it with anyone.

Discord handles everything you send through Discord. Discord has its own privacy policy, and it still applies.

Your choices

  • Run /forgetme to delete your user ID, your password hash and any blocked link logs about you.
  • Anonymous messages are not linked to you, so /forgetme cannot find them. If you want one removed, contact us and tell us what it says.
  • Do not want the bot to read messages? Remove it from your server.

Security

Passwords are hashed with argon2id. Too many wrong password tries will lock you out for a while. No system is perfect, so please use a password you do not use anywhere else.

Children

Sakerhet is only for people who are allowed to use Discord. Discord's minimum age rules apply.
